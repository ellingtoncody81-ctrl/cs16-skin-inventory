## 四、工具 `src/cs_skin_gui.py`

| 项 | 值 |
|---|---|
| 行数 | 26 行长行（压缩书写） |
| 编码 | UTF-8 |
| 依赖 | `Pillow` · `tkinter`（标准库） |
| 支持武器 | 24 把枪 + 19 种刀 |
| 支持资源 | 武器皮肤 / 匕首 / 手套 / 印花 |

核心常量：

| 常量 | 作用 |
|---|---|
| `TEX_ENTRY_SIZE = 80` | MDL 纹理表单项字节数 |
| `WEAPON_MAP` | 模型文件 → 显示名 + 贴图目录 |
| `KNIFE_ENTRIES` | 19 种刀型映射 |
| `EXCLUDE_WEAPONS` | 排除清单 |

核心函数：

| 函数 | 作用 |
|---|---|
| `parse_mdl(data)` | 校验 `IDST` + version 10，解析 header |
| `get_textures(data, info)` | 遍历纹理表，返回名称/宽/高/数据偏移 |
| `read_bmp_texture(path, w, h)` | 读 BMP，P 模式直取 / 其他模式量化 256 色 |
| `replace_texture_in_mdl(...)` | 覆写像素块 + 768 字节调色板 |
| `scan_skins/scan_glove_skins/scan_stickers` | 扫描三类贴图目录 |
