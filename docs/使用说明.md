# 使用说明

## 快速开始

### 方式一：直接运行 EXE

1. 确认文件夹结构完整（工具靠同级 `cstrike\` 定位资源）：

   ```
   csgo-inventory-cs16\
   ├── cs_skin_gui.exe
   └── cstrike\
       ├── models\
       ├── sound\
       └── CSGO Texture Pack\
   ```

2. 双击 `cs_skin_gui.exe`

### 方式二：源码运行

```bash
pip install -r requirements.txt
python src/cs_skin_gui.py
```

> 需要 Python 3.8+，Windows 系统。
> 依赖只有 `Pillow`；`tkinter` 随 Python 官方安装包自带。

## 换肤流程

```
选中武器  →  选中皮肤  →  应用皮肤  →  cstrike\models\v_xxx.mdl 被覆写
                                              ↓
                                        启动游戏生效
```

## 重要提示

> ### ⚠️ 工具会直接覆盖模型文件
>
> 首次使用前，**请先备份整个 `cstrike\models\` 目录**：
> ```bash
> xcopy cstrike\models cstrike\models_backup /E /I
> ```
>
> 换肤**不可撤销**（没有内置的撤销功能）。

### 皮肤名对不上？

工具的映射逻辑是内置在 `src/cs_skin_gui.py` 顶部的几张表：

| 表名 | 作用 |
|---|---|
| `WEAPON_MAP` | CS1.6 模型文件名 → 显示名 + 贴图目录名 |
| `KNIFE_ENTRIES` | 19 种 CS:GO 刀型 → 贴图子目录 |
| `EXCLUDE_WEAPONS` | 不参与换肤的模型（第一人称不可见、瞄准镜等） |

如果你想给某把武器加新皮肤，编辑 `WEAPON_MAP` 即可，
或直接在 `cstrike\CSGO Texture Pack\<武器名>\` 里丢 `.bmp` 文件。

## 从源码重新打包 EXE

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name cs_skin_gui src/cs_skin_gui.py
```

产物在 `dist\cs_skin_gui.exe`。

> `--onefile` 打包后，`get_exe_dir()` 会返回 exe 所在目录，
> 所以 **`cstrike\` 必须和 exe 放在同一层**。

## 常见问题

**Q：换了皮肤游戏里没变化？**
- 确认是 `v_` 开头的模型（第一人称 viewmodel）被改了，不是 `p_` 开头
- 贴图尺寸必须与模型要求一致，工具会自动缩放但比例可能失真
- 换完要**重开游戏**（或重连服务器），热重载无效

**Q：贴图显示不正常 / 花屏？**
- 贴图必须是 **8 位索引色 BMP**。24 位真彩色 BMP 会被工具自动量化，
  但量化后可能与原图有出入
- 尺寸比例必须是 **2:1**（512×256 / 1024×512 等），否则缩放会变形

**Q：刀子的贴图找不到？**
- `classic` 目录：CT 显示 `knife_ct.bmp`，T 显示 `knife_t.bmp`
- `classic_css` 目录：显示 `classic` 目录下除 `knife_ct/t.bmp` 外的所有贴图

**Q：能自己加贴图吗？**
可以。往 `cstrike\CSGO Texture Pack\<武器名>\` 里丢 `.bmp`，
下次启动工具就会自动列出来。建议 **512×512，8 位索引色**。
